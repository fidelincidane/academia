# Academia

Academia web responsive construida con **HTML + Sass + Vite**, pensada para desplegar en GitHub Pages.

## Demo en vivo 🌍

👉 **Ver sitio publicado:** [https://fidelincidane.github.io/academia/](https://fidelincidane.github.io/academia/)

## Tecnologias 🛠️

- **Frontend:** HTML5 + JavaScript (ES Modules)
- **Estilos:** Sass (SCSS) con BEM y mobile-first
- **Build/Dev Server:** Vite
- **Deploy:** GitHub Pages

## Requisitos 📋

- Node.js 18+
- npm 9+

## Instalacion local 🚀

```
npm install
npm run dev
```

## Scripts disponibles ⚙️

- `npm run dev` - Inicia servidor local con Vite
- `npm run build` - Genera build de produccion en `docs/`
- `npm run preview` - Previsualiza el build generado

## Despliegue en GitHub Pages 🌐

### Pasos ✅

1. **Construir proyecto**
   - `npm run build`
2. **Publicar carpeta docs/ en GitHub Pages**
   - Ve a Settings -> Pages
   - Selecciona rama master y carpeta /docs
3. **Verificar en GitHub**
   - Revisa que la rama de Pages este activa

## Paginas del sitio 📄

- **Inicio** — Hero con fotos ciclicas, cursos, noticias del blog
- **Cursos** — Listado de cursos disponibles
- **Blog** — Noticias y articulos del sector
- **Quienes somos** — Equipo de profesores
- **Contacto** — Formulario de contacto
- **Registro / Login** — Formularios de autenticacion
- **Aviso legal** — Informacion legal
